# Contributing to Kerala Tech Directory

Thank you for helping build Kerala Tech Directory!

We welcome contributions from everyone, including beginners making their first open-source contribution.

## How to contribute

1. Fork this repository.
2. Add or update company information in `companies/companies.json`.
3. Make sure the information is accurate and publicly verifiable.
4. Submit a Pull Request describing your changes.

## Guidelines

- Only add companies with a verifiable presence in Kerala.
- Use official company websites whenever possible.
- Do not submit duplicate entries.
- Do not add personal contact details.
- Do not guess missing information.
- Keep entries consistent with the existing data format.
- Include a source URL whenever possible.

## First-time contributors

If this is your first contribution, don't worry! We welcome beginner-friendly Pull Requests.

You can also open an issue if you are unsure how to add a company.

Thank you for contributing ❤️
