# Kerala Tech Directory

An open-source directory of IT companies, startups, and technology businesses across Kerala, India.

Our goal is to make Kerala's technology ecosystem easier to discover for developers, students, job seekers, entrepreneurs, and anyone interested in the tech industry.

## What is this?

Kerala Tech Directory is a community-driven project that collects publicly available information about technology companies operating in Kerala and organizes it into an open, accessible dataset.

## What can you find here?

- IT and software companies
- Product-based companies
- IT service companies
- Startups
- SaaS companies
- AI and technology businesses
- Companies across all districts of Kerala

## Contributing

Contributions are welcome! You can help by:

- Adding new companies
- Correcting company information
- Updating website or career links
- Improving documentation
- Helping maintain and verify the dataset

You don't need to be an experienced developer to contribute.

## Coverage

We aim to cover all 14 districts of Kerala, not just major IT parks or cities.

## Disclaimer

This is a community-maintained directory and is not an official directory of any government agency, IT park, or organization. Company information should be verified using publicly available sources.
